💳 Bank Loan Analysis Dashboard

📌 Overview

This project is a professional Bank Loan Report Dashboard built using Power BI and powered by data from Microsoft SQL Server. It analyzes over 38,000 loan applications to provide a comprehensive view of bank funding, loan defaults, and key performance indicators (KPIs) for insightful business decision-making.

⚠️ Problem Statement

Financial institutions process thousands of loan applications regularly, making it difficult to manually track loan performance, assess risk, and monitor funding targets. Decision-makers need a centralized, automated solution to instantly evaluate critical metrics—such as default rates (Bad Loans), average interest rates, and Debt-to-Income (DTI) ratios—to mitigate financial risk and optimize lending strategies over time.

🎯 Key Highlights

KPI Tracking: Monitors Total Funded Amount, Total Received Amount, Average Interest Rate, and Average Debt-to-Income (DTI) with MTD and MoM performance tracking.

Loan Segmentation: Visualizes "Good vs. Bad" loans and provides a detailed status breakdown (Fully Paid, Charged Off, Current).

Interactive Navigation: Clean layout featuring Summary, Overview, and Details pages.

Dynamic Slicers: Filter data instantly by State, Grade, Purpose, and Loan Quality.
